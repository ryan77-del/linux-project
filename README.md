# 🚀 Infraestrutura como Código (IaC) com Bash

Projeto de Infraestrutura como Código (IaC) desenvolvido com Shell Script para automatizar a configuração inicial de um ambiente Linux, realizando criação de usuários, grupos, diretórios e permissões.


## 📌 Objetivo do Projeto

O objetivo deste projeto é praticar conceitos de administração Linux e automação de tarefas utilizando Shell Script, reduzindo processos manuais e tornando a configuração do ambiente mais padronizada.

## 🏗️ Sobre o Projeto

Este projeto automatiza a criação de uma estrutura básica de servidor Linux:

- Criação de diretórios
- Criação de grupos
- Criação de usuários
- Definição de permissões
- Organização de acessos por departamento



## 🛠️ Tecnologias Utilizadas

Liste as ferramentas:

- Linux
- Bash / Shell Script
